# Cotisation Foncière des Entreprises

## Présentation

La CFE pour *Cotisation Foncière des Entreprises* est un impôt local, qui doit être réglé annuellement, au plus tard le **15 Décembre**.

Elle est composée :
- D'une taxe fixe, variant selon la commune où est domiciliée l'entreprise
- De taxes additionnelles (non concernées par les activités libérales BNC) :
	- Taxe CCI, pour permettre le financement des Chambres de Commerce et d'Industrie.
	- Taxe CMA, pour permettre le financement des Chambres de Métiers et de l'Artisanat.

Pour connaître son **taux d'imposition**, nous pouvons nous rendre sur le [site des données de fiscalité locale](https://data.economie.gouv.fr/pages/fiscalite-locale-particuliers/).

## Payer l'impôt

1. Se rendre sur son espace professionnel du service des impôts.
2. Cliquer sur **Avis CFE** dans la rubrique **Mes services**.
3. Sur la nouvelle page, cliquer sur le bouton **Accès aux avis de CFE**.
4. Dans le tableau, choisir la ligne pour la période d'imposition de l'année en cours et cliquer sur Avis d'imposition.
5. Cliquer sur le bouton **Payer** sur la page présentant l'avis de CFE.

# Eviter la double imposition

Avant de régler la **CFE**, il est important de vérifier le détail des calculs.

1. Se rendre sur la page présentant l'avis de CFE
2. Cliquer sur la flèche page suivante située en haut à gauche.
3. La taxe fixe peut être consultée dans le champ n°25
4. La taxe CCI peut être consultée dans le champ n°35
5. La taxe CMA peut être consultée dans le champ n°47
	1. Ce champs n'est pas rempli : rien à signaler.
	2. Sinon il faut contacter le **SIE**.
